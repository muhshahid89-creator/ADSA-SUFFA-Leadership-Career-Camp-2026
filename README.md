## 🚀 എങ്ങനെ തുറക്കാം? (How to Run / Open)

1. ഫയൽ എക്സ്പ്ലോററിൽ (File Explorer) **`D:\dars`** ഫോൾഡർ തുറക്കുക.
2. **`index.html`** എന്ന ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക (ബ്രൗസറിൽ വെബ്സൈറ്റ് ഓപ്പൺ ആകും).
